Ocarina

Ocarina reads the transcript your agent already writes, on your machine, and shortens what you asked for into a few words. No model, no network: the titles are earned with plain string work. The dot beside each one is the shell reporting whether that tab is working, waiting, or has just failed.

Your Mac sleeps. Your agent stops.

Start a long run, walk away, come back to a display that went to sleep and a job that went with it. It is the most annoying way to lose twenty minutes of work.

Ocarina holds the same wake assertion caffeinate -d holds, from the moment you open it. On by default, because the point is not having to remember.

# a real assertion, and it names who holds it
~ › pmset -g assertions

Everything else in the window

Fourteen themes, and none can hide an error

Colour, texture and type move together. Every one is measured against a contrast floor before it is offered, because a palette that hides red text is a palette that ends the session.

Small things that stop you getting stuck

It reads a risky paste back to you

You are following instructions you cannot check. Ordinary commands paste silently; only text that runs several things, or deletes something, stops for a sentence.

⚠ This is 3 separate commands, not one.
⚠ rm -rf deletes files permanently.
⚠ sudo runs as administrator.
