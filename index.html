Questions

Do I need to know how to code?

No. Ocarina doesn’t replace your coding agent, but it makes working with one easier. Some understanding of the project you are building will still help.

Is it a real terminal?

Yes. Normal terminal commands still work.

Does Ocarina include Claude Code, Codex or Gemini?

No. Ocarina is the workspace around those tools. You use the agent and the account you already have.

Is Ocarina an AI coding tool?

Not exactly. It is a terminal designed around the way people use AI coding agents.

Is Ocarina only for AI coding?

No. It works as a normal terminal as well, but its interface is built around agent workflows.

Does Ocarina send my terminal history somewhere?

Ocarina’s own history and organisation stay on the Mac. The third-party coding agents you run inside it have their own data policies.

How much does it cost?

Ocarina is free and open source. The agents you run inside it are billed by whoever makes them.

Which platforms are supported?

macOS 14 and later, for now.
