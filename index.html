One window, a tab for every agent.

Open everything in the same window and the sidebar names each tab after what you asked for — nothing to juggle, nothing called zsh. The name is taken from the ask that opened the conversation, so it holds still instead of changing under you every time you type.

One window, one list, each tab named after what you asked for. The dot says working, waiting, or stopped — read from the agent’s own transcript, so it goes green when the work stops rather than blinking at work that finished ten minutes ago.

Your Mac stays awake while the agent works.

Ocarina holds the display awake for as long as a run is going, so a long task finishes instead of stopping when the screen does. Same task, same machine, side by side.
