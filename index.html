Intro

A developer terminal earns its keep with power — panes, plugins, profiles, a config language. All of it assumes you know what to type, what broke, and what to install.

For someone whose first terminal is this one, every one of those assumptions fails at the same moment, and the session ends. Ocarina removes the need to know rather than adding another way to be expert.

It carries the commands you would otherwise find in a browser. It reads what you asked your coding agent and keeps the list. When something fails, it offers to explain it.

What makes it great?

The details are all the same detail.

Assume the person reading cannot yet recover from a mistake, and design so they never have to.

01

Nothing runs itself

Every path that puts a command in front of you types it and stops. The last act is always yours.

02

Legibility is enforced

All sixteen ANSI colours in every theme are contrast-checked. A theme that fails is listed as broken, not quietly shipped.

03

It says what it can support

“Finished”, never “done”. A refused keep-awake shows as refused. The interface does not claim more than it knows.

04

A paste is read first

Ordinary commands paste silently. Only multi-command or destructive text stops for a sentence.

05

It knows when work is happening

A dot per tab, driven by the shell itself, so a silent sleep still reads as busy and a failure reads as red.

06

Small on purpose

No plugin system, no scripting layer, no profile format. One window you can describe in a sentence.

Who is it for?

People building with agents, not with tooling.

And, just as importantly, people it is not for.

You describe, an agent writes

The terminal is simply where that happens. You do not want to get good at it — you want it to stop being the obstacle.

Your first terminal is this one

No technical background assumed. If you have never installed anything from a command line, the first thing you need is already behind ⌘K.

Not for everyone

If you want tmux integration, split panes, a plugin ecosystem and a config language, this is the wrong terminal and always will be.
