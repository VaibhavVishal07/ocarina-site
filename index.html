Nothing here you have to switch on.

The tab names, the task list, the meter and the menu bar all run from the moment you open the app. You will not find a preference for any of them.

Every tab says where it is.

Ocarina names each tab for the checkout it works in, so a tab inside Sources/OcarinaUI still reads Ocarina.

Everything you asked, still on the screen.

Ocarina reads the agent’s transcript and ticks each job off as it finishes.

Ocarina puts the state in the menu bar.

You can check a tab you are not looking at without returning to the window. Ocarina sets the words in its own 5x7 lettering.

Your Mac stays awake while the agent works.

Ocarina holds the display on while a run is going, so a long task reaches the end.

Keeping the display awake

It counts what you have spent.

Ocarina shows the tokens you have spent and the time left in the five-hour window. It shows no percentage, because nothing on your machine records the size of the allowance.

Ask for a skill in your own words.

A skill is a folder of instructions your agent reads when a task needs it. Ocarina ships 216 of them and installs each one to whichever agent is in your tab.

Questions

Do I need to know how to code?

No. Ocarina is the window around your coding agent.

Is it a real terminal?

Yes. Normal terminal commands still work.

Does Ocarina include Claude Code, Codex or Gemini?

No. You bring the agent and the account you already have.

How much does it cost?

Free and open source, for macOS 14 and later. Whoever makes the agents inside it bills you for those.
