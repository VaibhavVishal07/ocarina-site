It opens with a way in

Not an empty prompt. A board that says what the two keys you need actually do.

Every command a beginner needs first, already written and already checked.

Choosing types it. It does not run it.

When it breaks, it offers to explain

A failure is where people stop. It is the one moment worth interrupting.

It remembers what you asked for

Ticked when the agent finished talking. Never "done", because that is all it can know.

Fourteen of them, each with its own colour, texture and weight.
